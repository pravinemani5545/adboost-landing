# AdBoost Health — Landing Page

Astro landing page for AdBoost Health: growth marketing for health, telehealth, supplement, and health-app brands.

## Stack
- Astro 5 (static)
- Vanilla CSS (inline tokens, no Tailwind)
- Vanilla JS (scroll reveal, animated counters, SVG draw-on, FAQ accordion)
- Geist + Instrument Serif via Google Fonts

## Develop
```bash
pnpm install
pnpm dev
```

Open http://localhost:4321

## Build
```bash
pnpm build
pnpm preview
```

## Deploy
Static output in `dist/`. Drop on any static host (Vercel, Netlify, Cloudflare Pages).
